# 来源接口及口径

assignment.py登记食堂为随机化单位，同block固定鼓励数，draw按真实机制抽签。adoption.py以营业窗口供餐量汇总实际小份餐执行比例，未给执行资料返回None。weighing.py按known/revision读取称重，waste_kg=None表示缺称，不能当0；已称总湿重与供餐暴露并列输出，没有计算效应或工具变量估计。adopted是预登记adoption_threshold门槛下的食堂二元执行标记，按该期间窗口供餐量加权执行比例判定；门槛与窗口在抽签前冻结，不得按称重结果挑选。主要效果以食堂等权，称重标准化到每份餐，缺称引起的不可观测结果需单列；鼓励对食堂的分配在试验前冻结。所有资料为合成试验记录。

输入为UTF-8 JSON，金额用十进制字符串，时间为样例约定的整数日/周/月。行内null是明确状态，不自行推断为数值0。样例范围不限制实际数据规模。
